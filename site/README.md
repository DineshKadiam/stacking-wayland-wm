# CoW website

The website is generated by [Hugo](https://gohugo.io/). 

It follows the usual Hugo structure, see: `static/`

Build a local copy from the repository root with:

```sh
sh site/build.sh
python3 -m http.server 8000 --bind 0.0.0.0 --directory _site
```

This has been cobbled together from various other bits of Hugo themes, etc.
